# Recetario Desktop — canal de actualizaciones de prueba

Este repositorio aloja exclusivamente releases de prueba para las actualizaciones de Recetario Desktop. El código fuente se mantiene en [MacarronRecetario](https://github.com/RandyZam04/MacarronRecetario).

Los instaladores y metadatos de `electron-updater` se publican como archivos adjuntos de cada release. No se almacenan aquí bases de datos, fotografías, respaldos ni datos de clientes.
